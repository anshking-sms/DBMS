# Food Donation Management System

## Project Overview
The Food Donation Management System is a database project designed to organize food donation information and help manage surplus food donations.

## Problem Statement
Food wastage and the difficulty of organizing donation records create a need for a structured system to store and manage food donation information.

## Objectives
- Store food donation details in a database.
- Organize donation records in structured tables.
- Retrieve and manage records using SQL queries.
- Demonstrate relational database concepts and CRUD operations.

## Technologies Used
- MySQL
- SQL
- MySQL Workbench
- Visual Studio Code (for editing project files)

## Database
Database name: `food_donation_db`

## Setup Instructions
1. Install MySQL Server and MySQL Workbench.
2. Open the supplied SQL file in MySQL Workbench.
3. Execute the script to create the database, tables and sample records.
4. Select the database using `USE food_donation_db;`.
5. Execute the demonstration queries provided with the project.
